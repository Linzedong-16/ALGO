# 三数之和

## 题目描述
给你一个包含 n 个整数的数组 nums，判断 nums 中是否存在三个元素 a，b，c ，使得 a + b + c = 0？请你找出所有和为 0 且不重复的三元组。

## 题型分析
- **题型分类**：数组处理、双指针、排序问题
- **难度等级**：中等
- **核心考点**：排序+双指针技巧、去重处理

## 解题思路

### 方法：排序 + 双指针

#### 思路解析
三数之和等于0，可以转化为：对于每个元素 a，寻找两个元素 b 和 c，使得 b + c = -a。这就变成了经典的"两数之和"问题。

#### 核心思想
1. **先排序**：排序后可以利用有序性，使用双指针快速查找
2. **固定一个数**：遍历数组，将每个元素作为第一个数
3. **双指针查找**：用左右指针在剩余数组中查找满足条件的两个数
4. **去重处理**：跳过重复的数字，避免结果重复

#### 算法步骤
1. 对数组进行升序排序
2. 遍历数组，对于每个元素 nums[i]：
   - 如果 i > 0 且 nums[i] === nums[i-1]，跳过（去重）
   - 设置左右指针：left = i+1, right = nums.length-1
   - 计算三数之和：sum = nums[i] + nums[left] + nums[right]
   - 根据sum的结果移动指针：
     - sum === 0：找到解，加入结果，移动指针并跳过重复值
     - sum < 0：left++（需要更大的数）
     - sum > 0：right--（需要更小的数）

## 代码实现

```javascript
/**
 * 排序与双指针的方式，三数相加为0
 * @param {Array<number>} nums
 * @returns {Array<Array<number>>} res
 */
var threeSum = function (nums) {
  const res = [];
  nums.sort((a, b) => a - b); // 关键条件:先排序
  
  for (let i = 0; i < nums.length - 2; i++) {
    // 跳过重复的第一个数
    if (i === 0 || nums[i] !== nums[i - 1]) {
      let left = i + 1,
          right = nums.length - 1;
      
      while (left < right) {
        const sum = nums[i] + nums[left] + nums[right];
        
        if (sum === 0) {
          res.push([nums[i], nums[left], nums[right]]);
          
          // 结果去重，指向连续相同的值的最后与最初的两位,跳过双指针重复的数字
          while (left < right && nums[left] === nums[left + 1]) {
            left++;
          }
          while (left < right && nums[right] === nums[right - 1]) {
            right--;
          }
          // 进入下一位与前一位
          left++;
          right--;
        } else if (sum > 0) {
          right--; // 需要更小的数
        } else {
          left++;  // 需要更大的数
        }
      }
    }
  }
  return res;
};
```

## 复杂度分析

- **时间复杂度**：O(n²)
  - 排序：O(n log n)
  - 外层循环：O(n)
  - 内层双指针：O(n)（每个元素最多被访问一次）
  - 总体：O(n log n + n²) = O(n²)

- **空间复杂度**：O(1)
  - 不考虑结果存储空间，只使用常数个额外变量

## 示例演示

### 输入：`[-1, 0, 1, 2, -1, -4]`
1. **排序后**：`[-4, -1, -1, 0, 1, 2]`
2. **遍历过程**：
   - i=0, nums[0]=-4：寻找两数和为4，无解
   - i=1, nums[1]=-1：寻找两数和为1
     - left=2(-1), right=5(2), sum=0 → 找到 [-1, -1, 2]
   - i=2, nums[2]=-1：跳过（重复）
   - i=3, nums[3]=0：寻找两数和为0
     - left=4(1), right=5(2), sum=3 > 0 → right--
     - left=4(1), right=4，结束

**输出：`[[-1, -1, 2], [-1, 0, 1]]`**

## 关键点总结

### 1. **排序的重要性**
- 排序后可以利用双指针的二分查找思路
- 排序后重复元素相邻，便于去重

### 2. **去重策略**
- 外层循环：跳过重复的第一个元素
- 内层双指针：找到解后跳过重复的左右指针值

### 3. **双指针移动规则**
- sum < 0：需要更大的数 → left++
- sum > 0：需要更小的数 → right--
- sum = 0：找到解，记录并移动两个指针

### 4. **边界条件处理**
- 数组长度小于3直接返回空数组
- 注意指针移动的边界检查
