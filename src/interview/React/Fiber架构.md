# 什么是Fiber？解决了哪些问题？

> Fiber：是React16 推出的新渲染架构，之前直接递归遍历VDOM树去渲染，由于递归有压爆执行栈的风险并且一旦执行就不可打断恢复，必须占用主线程，也就会导致页面卡顿。有了Fiber，将VDOM 进一步转换成 由 `child`、`return`、`sibling` 组成的Fiber链表节点，并且通过 迭代 + 链表的形式，实现任务的 拆分、暂停和恢复

1. 增量渲染，避免卡死主线程：Fiber把任务都拆分成小单元，通过时间分片调度，能再需要时让出主线程保证用户的交互、页面不卡
2. 任务优先级可更新：因为任务都可中断，可以更新优先级划分，把用户交互、动画按照较高优先级处理，网络数据更新等可以降低优先级，高优先级任务可以插队打断低优先级的，保证响应速度
3. 是并发的基础：后续React提供了诸如 Suspense、useTransition（Tab、筛选条件切换）、useDeferredValue（值延迟更新，搜索框+下拉列表） 等新API，提供了基础，用于进一步定制化 引用的交互效果
