## JSX理解

JSX是一种JavaScript的语法扩展，需要在工程化环境通过bable之类的工具转译，其具有以下特点：

1. 转译后，其本质就是 React.createElement() 或 \_jsx() 函数，其主要作用在于提供 声明式UI
2. 这两种函数的输出就是虚拟DOM，是后续的DIFF优化 & 批量更新 基础
3. 融合JS全部能力，不引入传统模板语法的 指令而是用 JS的表达式去构建动态复杂UI
4. 视图和逻辑内聚在 组件中，组件化开发体验好

> JSX 是 JavaScript 的语法扩展，不是独立模板。经过 Babel 编译为`_jsx`或者`createElement`函数调用，产出 JS 对象，也就是虚拟 DOM。它最重要的是提供了声明式UI提高开发效率，我们可以直接使用 JS 全部能力来描述界面（JS表达式），而不用传统模板引擎提供的指令进行UI构建，逻辑和视图内聚在组件内部，提升组件化开发体验
