# 网络层、传输层：两个模型（面试必分清）

## 1、OSI七层模型（理论教科书模型）

| 层数  | 名称       | 代表协议               |
| ----- | ---------- | ---------------------- |
| 7     | 应用层     | HTTP、FTP、DNS         |
| 6     | 表示层     | 编码、加密解密         |
| 5     | 会话层     | 会话建立维护           |
| **4** | **传输层** | **TCP、UDP**           |
| **3** | **网络层** | **IP协议（IP数据包）** |
| 2     | 数据链路层 | 以太网                 |
| 1     | 物理层     | 网线、光信号           |

> ✅ **传输层(4层)：TCP/UDP，处理端口，TCP报文段，FIN/ACK/SYN标志在这里**
> ✅ **网络层(3层)：IP协议，处理IP地址、路由选路，IP数据包，TTL在这里
> 应表会，传网数物**

## 2、TCP/IP四层模型（现实互联网实际在用，考试面试高频）

现实互联网不用完整OSI七层，把上面三层合并。

| 层数  | 名称               | 内容                             |
| ----- | ------------------ | -------------------------------- |
| 4     | 应用层             | HTTP、HTTPS、DNS（合并OSI7‑5层） |
| **3** | **传输层**         | **TCP、UDP，端口，TCP报文段**    |
| **2** | **网际层(网络层)** | **IP协议，IP数据包，路由**       |
| 1     | 网络接口层         | 网卡、以太网                     |

应 传 网 接

### 🎤面试口语口述回答（直接背）

> 网络层、传输层，最早来自OSI七层参考模型；我们实际互联网用的是TCP/IP四层模型，概念是对应的。
>
> **传输层：对应TCP/UDP，管端口号，就是FIN、ACK这些标记所在的层，单元叫TCP报文段。**
>
> **网络层（网际层）：对应IP协议，管IP地址和路由转发，单元是IP数据包。TCP报文段会被封装放进IP包里面传输。**

### 封装通俗比喻（方便记忆）

- 应用层：你写的聊天文字（业务数据）
- 传输层(TCP)：套上TCP信封，写上端口，打上FIN/ACK标记 → **TCP报文段**
- 网络层(IP)：再套一层IP快递盒，写上双方IP地址 → **IP数据包**
- 链路层：再打包成以太网帧，交给网卡网线发出去

### 高频坑

1. 很多人口语会混用两套模型名词，**传输层、网络层这两个名词两套模型都有，含义一样**。
2. OSI是理论；TCP/IP是真实互联网实现。面试讲TCP/IP四层更贴合实际。

### 顺带串你刚才的知识点

1. TCP报文段 → **传输层**
2. IP数据包 → **网络层**
3. FIN/ACK标志位在TCP头部，**传输层**，不在IP头
4. TTL（报文跳数限制）是IP头部，**网络层**
