# 一台服务器最多多少 TCP 连接

TCP 连接靠四元组区分，服务端同一个监听端口可以接收大量客户端。

连接限制来源：

1. 每个TCP连接，都对应Linux服务机上的一个占用的socket，一个socket对应一个Linux的文件描述符，Linux的文件描述符fd系统默认最多打开1024，需要调优，作为第一层限制可以轻松申请十万百万+的连接
2. 下一层是物理层面的限制，连接的核心瓶颈是内存，每个TCP连接都要在内存维护各自的 内核对象、收发缓冲区
3. 活跃连接的数据包处理需要消耗CPU处理
4. 单机遇到 CPU、内存、带宽或连接数瓶颈时，可以通过负载均衡做横向扩容，把流量分散到多台服务器。高性能网关通常也会部署成集群

> TCP连接由四元组（源IP、源端口、目标IP、目标端口）唯一确定，理论上限为`2^32 * 65535`

实际主要受限于三层资源瓶颈：

- 文件描述符（FD）：Linux默认为1024，调优后可达百万级
- 内存（最大瓶颈）：每个连接需分配内核缓冲区及维护内核对象
- CPU：活跃连接的数据包解析与拷贝消耗大量资源
- 后端部署通过负载均衡和高性能网关横向扩容，将连接分发到多台服务器

* **理论** **：四元组决定，** **没有上限**
* **限制一** **：** **文件描述符（FD）** **，可以调优到百万级**
* **限制二** **：** **内存** **（每个连接都要吃内存，最大瓶颈）**
* **限制三** **：** **CPU** **（处理活跃数据包的消耗）**
* **解决** **：上\***负载均衡\*横向扩容
