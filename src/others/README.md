> 简单DP

1. 爬楼梯
   经典入门 DP，dp[i] = dp[i-1] + dp[i-2]
2. 最大子数组和
   状态：dp[i] = max(nums[i], dp[i-1] + nums[i])
3. 买卖股票的最佳时机
   一次交易，简单 DP / 一次遍历即可
4. 打家劫舍
   不能相邻，dp[i] = max(dp[i-1], dp[i-2] + nums[i])

5. 使用最小花费爬楼梯
   爬楼梯变种，带 cost
6. 区域和检索 - 数组不可变
   前缀和思想，也算简单 DP
7. 第 N 个泰波那契数
   斐波那契变种
8. 斐波那契数
   基础中的基础

9. 比特位计数
   位运算 + DP，dp[i] = dp[i & (i-1)] + 1
10. 获取生成数组中的最大值
    模拟 + DP，非常简单
11. 除数博弈
    找规律 DP，简单判断奇偶
12. 粉刷房子
    相邻不同色，状态很少，极简单
