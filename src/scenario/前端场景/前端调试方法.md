## 前端开发、线上是怎么调试代码的？

1. 开发者工具调试:
   1. sources断点：逐行执行脚本、查看调用栈、变量实时值
   2. watch监听：追踪部分变量变化
   3. 条件断点：快速定位断点的逻辑，避免调试定位耗时
   4. blackbox调试：跳过第三方库，专注业务代码
2. console对象方法：
   1. table：数组对象格式化
   2. dir：完整DOM对象属性
   3. time&timeEnd：查看脚本执行耗时
   4. trace：查看完整调用栈
3. 网络与性能：
   1. Network面板：接口响应耗时、排队状况、缓存、资源体积等
   2. Performance：排查回流重绘、长任务、
   3. Memory：主要排查内存泄漏问题、闭包、对象引用
   4. **Lighthouse**：一键打分，FCP、FP、LCP等性能指标及SEO优化
4. 线上与工程化配置：
   1. source-map：线上环境报错定位源码
   2. 抓包工具：Fiddler抓包比network面板更详细丰富
   3. 错误监控平台：通过对线上的埋点数据收集判断项目的问题
   4. Vite / Webpack：代理配置、环境区分等
