## 基础扫盲

关键的资源加载标签

1. link：下载各种资源js、css、字体等，属性如下：
   1. stylesheet
   2. preload
   3. prefetch
   4. preconnect
   5. dns-prefetch
   6. modulepreload
2. script：下载并执行JS代码，
   1. defer：后台下载JS，不阻塞DOM
   2. async：后台下载JS，阻塞DOM，因为下载完就执行
   3. type="module"：等于defer

## 首屏加载优化三步走战略

### 基础优化手段

1. 图片压缩
2. 字体裁剪
3. 全量路由懒加载
4. 代码分包
5. 网络方面CDN部署静态资源
6. Gzip压缩

### 关键路径优化

1. HTML解析：核心CSS样式内联避免外链阻塞
2. 资源加载：preload 提高首屏资源 如字体、图片等的优先级
3. 首屏非核心脚本：defer 后台下载并执行，不阻塞DOM操作
4. 非首屏资源：prefetch 后台加载
5. 渲染呈现：上骨架屏、SSR优化 保证不白屏
6. 数据请求：首屏接口 预请求缓存数据(`<link rel="preload" href="/api/home-data" as="fetch" crossorigin="anonymous>" `)

### 精细中级优化

1. 分级加载策略，首屏只渲染可视区域，非可视部分懒加载，长列表虚拟滚动优化
2. 低端机 (通过媒体查询适配、系统API判断机器性能)关闭复杂动效、弱网环境加载低清资源
3. 推迟非核心脚本加载，保证核心内容优先渲染
4. 埋点采集 LCP(最大内容绘制) FP(首次绘制) FCP(首次内容绘制)

Core Web Vitals有：

- LCP：Largest Contentful Paint｜最大内容绘制
- INP：Interaction to Next Paint｜交互到下一帧绘制
- CLS：Cumulative Layout Shift｜累积布局偏移
