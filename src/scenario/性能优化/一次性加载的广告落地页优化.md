# 一次性加载广告落地页渲染速度优化

1. 静态资源压缩：图片统一的webp、小图标base64内联、雪碧图合并，（尽量减少网络请求静态资源次数、网络请求带来的资源加载延迟）
2. 代码压缩：JS做Tree-shaking、CSS剔除废弃样式、对于主流现代浏览器必要剔除无用的兼容性样式或无用的 Polyfill 兼容性代码
3. 渲染优化：固定宽高，避免重排、DOM层级不宜过多、避免频繁的DOM操作或其他耗时操作（如定时器、高频事件监听滥用等）、动画用transform和opacity、对于高级动画（加载3D模型等）通过RAF 协调动画频率和will-change GPU加速优化效果
4. 网络加载：多域名部署资源触发浏览器建立多路TCP并发连接，依托CDN分发快速获取资源、核心资源使用preload预加载，次要资源prefetch获取，合理分配优先级、对次要内容延后渲染，如动态加载或懒加载
5. 体验优化：优先渲染业务主体内容，对于主体内容的样式提到内部样式中，并做骨架屏优化

> 代码压缩-人话：因为这是一次性的广告落地页，如果没有长期迭代和多版本兼容的负担，所以我在优化时会更激进一些，比如砍掉不必要的 Polyfill、不做代码分割，甚至把关键样式内联进 HTML，最大化压缩首屏加载时间，优先保证用户第一眼就能看到广告内容
